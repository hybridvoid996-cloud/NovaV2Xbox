# Nova AI / Codex studio — local update

- Full-screen Codex workspace with conversation on the left, token balance next to the composer, editor/explorer/preview, and runtime Console & Problems.
- File and folder imports are text-only, limited to 40 files, 30 KB per file, 120 KB per project. Folder creation creates a first file; folder paths appear in the explorer.
- HTML/CSS/classic JavaScript run in a sandboxed browser preview. Other languages can be edited as text but require external runtimes to execute. No shell, package installation, backend execution, network requests, or local filesystem access is granted to generated code.
- Local CSS and classic script references in the HTML can use imported project paths. Arbitrary build systems, module bundlers, binary assets and server languages are not supported by this preview.
- AI code responses request JSON output; malformed responses keep existing files. Additional project files are preserved when applying edits. Context and token limits still apply; large projects need smaller edits.
- Publishing, gallery and forking retain the authenticated account service. They are unavailable in the local key-only preview, which never charges real coins or writes public projects.
- Local key-only preview is explicitly enabled on a loopback server and rejects cross-origin requests. Keys stay in ignored .env.local.
