# Wii follow-up — November 1

Local only. Not deployed; not marked Working.

The supplied code-1 screen was reproduced. The in-page engine log reported `cannot read main.dol`. Three compatibility problems were identified:

- The game-config relative asset base escaped the proxy's virtual location. The pinned host module now resolves it against the inspected source folder. Explicit configured absolute asset bases remain intact.
- The source requests `game/part/sys/main.dol` or `game/main.dol`, while the published file is `game/sys/main.dol`. The existing scoped partition mapping is retained.
- Scramjet's synchronous XHR bridge returned status zero in workers. Worker requests now retain native synchronous XHR after URL rewriting. The window bridge is unchanged. The installed curl transport also misread HEAD responses as incomplete downloads; a scoped Wii HEAD handler uses a validated one-byte GET range to reconstruct the actual size.

Initial retesting passed the code-1 failure but showed zero frames. Diagnostics revealed it was checking sizes for 1,184 assets individually. A validated parser now loads the published 35,628-byte Wii file-system table once per worker and seeds its size cache. It rejects malformed tables and falls back to individual checks if unavailable. Existing game bytes, saves, and settings are not changed. The loading screen now waits for actual frames instead of hiding after 90 seconds; its file-read text reflects actual activity without inventing a completion percentage. Source launcher log uploads are disabled for this proxied game.

After indexing, browser verification reached the sideways-remote screen, save-data creation confirmation, title, file/player selection, introduction, and World 1 map. Keyboard controls navigated those screens. Attempts to enter 1-1 showed black transitions followed by a return to the map with fewer lives; no visible in-level movement was verified. This remaining behavior is unresolved and must not be described as full gameplay working. Proof of the repaired startup: `artifacts/game-audit/wii-after-startup-repair.png`.

Build and 20 related tests pass, including source-base resolution, partition paths, native worker XHR routing, validated range-derived HEAD metadata, file-index parsing and invalid data, scoping, and transport recovery. No existing local saves were deleted.
