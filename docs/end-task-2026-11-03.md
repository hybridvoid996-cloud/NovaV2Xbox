# Nova End Task

The bottom-right version/community dock now includes an activity icon before the update log: red when no tracked Nova task exists, green when one or more exist. Its upward-opening glass flyout lists retained app, game, cloud and system iframe contexts, the native Nova Music player, and a split-screen secondary context. Running, background-paused and playing-music states reflect the existing runtime flags. It does not inspect other browser tabs or operating-system processes, estimate CPU usage, or claim a task is busy merely because it exists.

End Task destroys the selected iframe browsing context and removes its Resume session reference, or disposes Music's service, listeners, timers, playback engine and audio node. Music opening requests are generation guarded so an ended pending import cannot restart playback. Stopping the visible frame returns home; other retained sessions remain. Existing resume/history entries and saved account data are preserved; unsaved in-memory state can be lost and the flyout says so. No new automatic stopping behavior is introduced. Existing Nova session limits are unchanged. Music can be reopened with a fresh player.

The dock remains accessible above active app frames. Menu state uses existing session/music events rather than a background polling loop. Icons tilt with pointer position and animate on click; explicit reduced-motion preference disables these effects.

Verified locally in the offline home preview: empty state red, NovaTube registered as one running task, End Task removed its iframe and returned to zero, Music registered with one native audio element, and End Task removed that audio element and its app UI. Six session lifecycle tests pass, including selected-task removal while preserving another app and recent-history records. Build passes. Not deployed.
